# 🌟 Plateforme Éditoriale Spirituelle

Bienvenue sur le dépôt officiel de la plateforme éditoriale **Spirituelle**. Ce projet a pour objectif d'offrir un espace web moderne, rapide et responsive pour la consultation et la gestion d'articles éditoriaux.

---

## 🛠️ Stack Technique

- **Front-End :** HTML5, CSS3, Tailwind CSS, JavaScript (ES6+)
- **Base de données / Back-End :** Supabase (PostgreSQL + RLS)
- **Gestion de version :** GitHub
- **Hébergement & CI/CD :** Vercel (Déploiement continu automatisé)

---

## 🚀 Déploiement

Toute modification poussée sur la branche principale (`main` ou `master`) déclenche automatiquement un build et un déploiement en production via **Vercel**.
